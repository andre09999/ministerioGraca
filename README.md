# Ministério Graça — Front-end

Site institucional responsivo do Ministério Graça, desenvolvido em React para apresentar a comunidade, seus projetos e formas de participação.

## Tecnologias

- React 18
- React Router
- Axios
- React Helmet
- React Toastify
- CSS responsivo

## Páginas

- início;
- sobre o ministério;
- oportunidades para servir;
- experiência dedicada ao Graça Kids.

## Executando localmente

```bash
git clone https://github.com/andre09999/ministerioGraca.git
cd ministerioGraca
npm install
npm start
```

## Build de produção

```bash
npm run build
```

## Backend

A API é mantida separadamente no repositório [ApiGra-a](https://github.com/andre09999/ApiGra-a) e hospedada no Render.
